# 组织与用户 / 角色管理 · 本地可点原型

离线 HTML 原型，覆盖组织树筛选（含下级）、用户 CRUD、所属组织须选岗位、部门/岗位一次性批量赋角、**角色功能权限矩阵**、预置三角色不可改删、删角色回收权限，以及**知识库实例权限示例**（公开性 + 成员）。角色页**无**资源/数据范围矩阵、无授权范围树。

## 打开方式

**方式一：单文件（推荐离线）**

用浏览器打开同目录的 `standalone.html`（CSS/JS 已内联）。

**方式二：分文件**

```
/workspace/org-admin-poc/prototype/index.html
```

**方式三：本地静态服务**

```bash
cd /workspace/org-admin-poc/prototype
python3 -m http.server 8765
```

浏览器访问：http://127.0.0.1:8765/

## 可交互页面

1. **组织与用户**
   - 左侧组织树（公司 → 子公司 → 部门 → 岗位）；点击任意节点筛选用户，**始终含下级**
   - **组织增删改**：顶部「+ 新增组织」或节点右键/「⋯」→ 新增子节点 / 编辑名称 / 停用（仅本节点）/ 删除；有子或有人不可删；层级：公司→子公司/部门，子公司→部门，部门→部门/岗位
   - 右侧用户表；所属组织列展示如 `生产部 / 生产1部 / 班长`
   - 新建 / 编辑用户：用户名、账号、密码（仅新建）、邮箱、手机、多选角色、**所属组织单一字段（只能选岗位）**
   - 部门或岗位节点右键 / 「⋯」→ **批量赋予角色**（一次性，仅当前成员）

2. **角色管理**
   - 左角色列表 + 右详情：**仅功能权限**模块分组勾选
   - 提示：Agent/知识库等数据权限请到资源详情「公开性设置」配置
   - **无「授权范围」树、无资源/数据范围矩阵**
   - 预置「管理员 / 子管理员 / 普通用户」：编辑与删除、保存权限禁用
   - 自定义角色可 CRUD；「保存权限」写入功能权限；删除时确认并回收用户上的该角色

3. **知识库权限示例**（实例 ACL，对齐现网）
   - 标题「测试知识库」；Tab：**基本信息** | **公开性设置**
   - 公开性：受限访问 / 公开访问
   - 成员管理：搜索、添加成员、表（账号/姓名/角色/操作）
   - 种子：`haha`=所有者（固定徽章）、`admin`=编辑者（下拉）
   - 添加成员弹窗：搜账号 + 选编辑者/使用者；可移除非所有者（内存态）

## 产品规则摘要（V1.9）

- 权限只经「角色 → 用户」；组织不承载权限
- 角色 = **功能权限包**；资源权限在**实例侧**（公开性 + 成员）；创建者默认所有者
- 管理员全部资源靠现网超级管理员开关，不靠角色勾数据范围
- 部门/岗位批量赋角 = 一次性快捷方式，不粘性继承
- 所属组织必须落到岗位
